# Hallium 2

Hallium 2 is the redesigned Hallium Korean-learning experience.

## Repository history policy

This repository intentionally preserves redesign milestones as Git history.

- `archive/original-visual-reference-2026-09-16` — frozen reference point before redesign implementation.
- `redesign/drive-audit-v1` — working redesign branch.
- `main` — approved integrated version.

The original interface was documented from 21 screenshots stored in the user's Google Drive on 2026-09-15/16. See `docs/original-visual-reference.md`.
